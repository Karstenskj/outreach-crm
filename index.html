Forbind til GitHub

Appen gemmer dine data i det private repo Karstenskj/outreach-crm-data. Indsæt en adgangsnøgle (fine-grained token) med adgang til det repo:

  1. github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new
  2. Repository access: Only select repositories → outreach-crm-data (vælg -data, ikke outreach-crm!)
  3. Permissions → Repository → Contents: Read and write
